# exp_065 — the local emergency card, November 2026

What can each local model be asked when the cloud cannot be trusted? For every candidate model on a 64 GB Mac mini and a 128 GB MacBook Pro: the usable context, the speed, which of 48 made-up defensive tasks it refuses, which it gets right, and whether its tool calls arrive. The result is one page per machine, repeated monthly with the same tests.

| File | What it is |
|---|---|
| [HYPOTHESIS.md](HYPOTHESIS.md) | the registration, written before any task, kit or run |

| `kit/card65.py` | the driver: tool calls, the tasks, the context ladder, per model file |
| `kit/score65.py` | blind packets for the judges; the tables |
| `kit/models65.json` | the model files, and which run with the borrowed chat template |
| `dev/` | probes and the smoke, made-up inputs only |

| `kit/tasks65.json` | the 48 tasks and keys, frozen (sha256 in the registration) |
| `kit/judging65.md` | how a judge marks an answer |
| `kit/apply_review65.py` | makes the task file from the writers' output and the reviewer's patches |
| `writer/` | the writers' output as returned, their notes, the review and its patches |

Status: registered 2026-11-27; tasks frozen; not run.
