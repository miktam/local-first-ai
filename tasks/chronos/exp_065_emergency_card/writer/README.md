# The writers' output, as returned

Two fresh cloud sessions wrote these on 2026-11-27 from the brief in the registration: `tasks-types-1-3.json` (suspicious messages, log extracts, scripts; in each type four tasks show something wrong and four show nothing wrong) and `tasks-types-4-6.json` (hardening, the first hour, reports to providers). `notes-*.txt` are the writers' own notes, including the keys they consider debatable.

**One mechanical change by the dispatcher, before the review:** the writers were told to write phone numbers as "+00 555 01xx". The privacy check that guards this repository accepts only the UK's reserved drama ranges as made-up numbers, so every "+00 555 0NNN" was replaced by "+44 7700 900NNN" (9 places). Nothing else was edited. The brief's placeholder was the dispatcher's mistake, not the writers'.

The frozen test file is `kit/tasks65.json`, made from these after the review; what the review changed is listed in `review.md`.
